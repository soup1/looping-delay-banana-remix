# looping-delay-banana-remix
This is a remix I did of the 4ms DIY Looping Delay Kit.  It was designed to fit in a 1590DD enclosure and has a built in power supply.  It adds balanced ins and outs with level controls and banana jacks for CV as the universe intended.  If by chance you would like to make one yourself here are all the files needed.  Please note you will still need to buy an expensive kit from 4ms and discard everything but the brain board…
